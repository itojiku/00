# Kunotes

Kunotes is a growing digital study space created by **Subhadeep Paul**.

## Open-source license

The Kunotes website source code is licensed under the [MIT License](LICENSE).
The academic PDF in `assets/` is provided as study material and is not covered
by the source-code license unless its own rights holder explicitly says so.

## Project structure

- `index.html` — subject-neutral landing page.
- `pages/` — the academic navigation pages and PDF reader.
- `assets/` — study material used by the website.
- `components/` — shared markup, including the footer.
- `scripts/` — shared navigation and PDF reader behavior.
- `styles/` — site and page styles.
- `vendor/pdfjs/` — local PDF.js files used by the reader.
